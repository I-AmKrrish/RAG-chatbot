<objective>
Integrate the hybrid retrieval and FlashRank re-ranking system into the DocMind user-facing applications and evaluation harness.
This plan updates `rag_pipeline.py` so `build_pipeline()` delegates to `build_retriever()` with full support for `search_type="hybrid"` while preserving backward compatibility with `"mmr"` and `"similarity"` (per D-05). It adds a retrieval mode selector to the Streamlit sidebar in `app.py` enabling real-time toggling between "Hybrid + Re-ranking" and "Standard MMR" (per D-06). Finally, it updates `evaluate_rag.py` with the `--search-type` CLI argument, records `search_type` in `results/runs.csv`, and executes a benchmark run against the evaluation dataset to verify that Hit Rate @ 4 and MRR match or exceed baseline MMR scores (per D-07, RETR-03).

Purpose: Connect end users and automated benchmarking to the hybrid retrieval pipeline with verified accuracy gains.
Output: Updated `rag_pipeline.py`, updated `app.py`, updated `evaluate_rag.py`, pipeline integration tests in `tests/test_retrieval.py`, and recorded benchmark metrics in `results/runs.csv`.
</objective>
