<objective>
Implement the core hybrid retrieval and cross-encoder re-ranking architecture for DocMind.
This plan establishes test infrastructure (`pytest.ini`, `requirements.txt`), creates an in-memory BM25 indexer built directly from ChromaDB chunks to guarantee 1:1 chunk parity (per D-02), fuses sparse and dense retrieval via LangChain `EnsembleRetriever` with balanced weights `[0.5, 0.5]` (per D-01), integrates local CPU cross-encoder candidate re-ranking via `FlashRank` (`ms-marco-TinyBERT-L-2-v2`) fetching 10 candidates and selecting top 4 (per D-03, D-04), and provides defensive fallback to raw ensemble candidates if re-ranking fails (per Agent Discretion).

Purpose: Enable sub-50ms hybrid retrieval and re-ranking with zero cloud API costs while providing automated test coverage and strict citation tracking.
Output: Configured `pytest.ini`, updated `requirements.txt`, core retrieval functions in `rag_pipeline.py`, and comprehensive unit tests in `tests/test_retrieval.py`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Query → BM25 Retriever | Untrusted query strings passed into BM25 tokenizer and BM25Okapi scoring |
| Candidate Chunks → FlashRank Model | Document chunk text passed into local ONNX cross-encoder model |
| Third-party packages → Virtual Environment | Package downloads from PyPI via uv/pip |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | BM25 query tokenizer | medium | mitigate | Sanitize user query into alphanumeric tokens without arbitrary regex execution; handle punctuation and whitespace safely. |
| T-01-02 | Denial of Service | FlashRank reranker inference | medium | mitigate | Enforce strict candidate depth `fetch_k=10` (per D-04) so cross-encoder computation is bounded to 10 passages (< 10ms on CPU). |
| T-01-SC | Tampering | pip dependencies | high | mitigate | Package legitimacy gate verified in 01-RESEARCH.md. Explicit version pinning: `rank-bm25==0.2.2`, `flashrank==0.2.10`, and `huggingface-hub>=2.4.0` in `requirements.txt`. |
</threat_model>
